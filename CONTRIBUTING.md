# Contributing to UNIXWIN

Thank you for contributing to UNIXWIN!

## Quick Start

1. Fork the repository
2. Create a branch: `git checkout -b feature/my-feature`
3. Make your changes
4. Test on Windows
5. Submit a Pull Request

## Development

### Prerequisites

- Windows 10/11
- Git for Windows
- Rust 1.70+ (for Rust projects)

### Building

Each project has its own build instructions. See the project README for details.

### Testing

Run tests before submitting:

```bash
# For Rust projects
cargo test

# For other projects
# See project-specific instructions
```

## Code Style

- Follow standard formatting (`cargo fmt` for Rust)
- Keep code clean and documented
- Match existing patterns in the project

## Pull Requests

- Keep changes focused
- Update documentation if needed
- Reference related issues

## Issues

- Use GitHub Issues for bugs and features
- Include OS and version information
- Provide steps to reproduce for bugs

## Questions?

Open an issue for any questions.
